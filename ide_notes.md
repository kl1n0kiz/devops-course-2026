# Заметки: IDE vs терминал

## Удобно в VS Code
1. Наглядный diff — сразу видно, что изменилось в файле
2. Быстрый commit через интерфейс — не нужно помнить команды add/commit
3. GitLens показывает историю прямо в коде (кто и когда менял строку)

## Удобнее в терминале
- Rebase и разрешение сложных конфликтов — в терминале больше контроля над процессом
