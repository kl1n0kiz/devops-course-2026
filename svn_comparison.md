# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это просто указатель (лёгкий файл-ссылка) на конкретный коммит,
создаётся мгновенно и не копирует файлы. В SVN ветка физически
копирует директорию проекта на сервере — операция медленная и занимает место.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN — централизованная система: у клиента нет полной копии истории,
все коммиты сразу уходят на единственный центральный сервер. Без сети
операция коммита невозможна. В Git, наоборот, у каждого разработчика есть
полная локальная копия репозитория, и коммит — чисто локальная операция.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- Legacy-проекты в госсекторе и банках, где вся инфраструктура уже завязана на SVN
- Работа с большими бинарными файлами при жёстком контроле доступа
  на уровне отдельных папок (SVN поддерживает гранулярные права на каталоги)
- Команды, которым принципиально важна линейная, строго последовательная
  история без параллельных веток
